# Asset Files

Place your creature sprite images in this directory.

## Naming Convention
Use the creature ID from creatures.json:
- `hop_spring.png` - Hop Spring (baby)
- `leap_coil.png` - Leap Coil (child)
- `spring_tank.png` - Spring Tank (child)
- etc.

## Format
- PNG with transparent background
- Recommended size: 512x512 to 1024x1024
- Will be scaled to fit in game
